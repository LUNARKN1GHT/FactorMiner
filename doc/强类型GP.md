# 强类型 GP（STGP）· GP 算法纵深

## 当前问题

普通 GP 生成树时**只看 arity**：`rank` 要 1 个孩子，随便塞什么都行。于是种群里混进大量「合法但无意义」的个体——`rank(rank(close))`（排名再排名，第二次近乎恒等变换）、`add(close, rank(volume))`（拿带量纲的价格水平去加一个无量纲排名）。这些废树占满搜索空间，稀释了算力。

## 设计：2 类 + 2 条规则

给每个原语标**类型签名**（输入要什么类型、输出什么类型），让生成 / 交叉 / 变异都只产生类型合法的树。贴着现有量价算子集，定两类：

- **`S`（series，带量纲）**：价格 / 量 / 额及其算术、时序变换。
- **`R`（rank，无量纲）**：截面归一化后的值 ∈[0,1]，即 `rank` 的输出。

两条规则覆盖全部算子：

| 算子 | 类型签名 | 作用 |
| --- | --- | --- |
| 终端 open…amount | → `S` | 原始数据都带量纲 |
| `rank` | `S → R` | 唯一改变类型的算子，输入只能 `S` |
| 算术 / 一元 / 时序 其余全部 | 泛型 `T → T`（子节点同型、输出同型） | 量纲一致才能运算 |

由此自动禁掉两类垃圾：`rank(rank(x))`（rank 要 `S`，里层 rank 给的是 `R`，对不上）、`add(close, rank(x))`（泛型算子要求孩子同型，`S`/`R` 混搭非法）；同时放行有意义的组合：`ts_mean(rank(close))`、`add(rank(a), rank(b))`。

**为什么交叉 / 变异只换同型子树就能保合法**：类型系统有「可替换性」——每个父节点只在乎孩子的**输出类型**，所以把一棵子树换成另一棵输出类型相同的子树，整棵树仍合法。交叉只在同型子树间换、变异只替成同型新树，合法性自动保住。

## 工程接入

- `tree.py`：`Node` 加 `out_type` 字段（`S`/`R`），生成时盖章。
- `stgp.py`（新）：类型化原语表 `PRODUCERS[T]` + `typed_random_tree` / `typed_crossover` / `typed_mutate` / `typed_ramped_half_and_half`，外加 `recompute_type` 自检工具（自底向上重推类型并校验）。
- `engine.py`：`GPConfig` 加开关 `strongly_typed`。
- `nsga2.py`：据开关选类型化 / 普通三件套，**非支配排序 / 拥挤度 / 环境选择等类型无关逻辑原样复用**。

好处是**一个 YAML 开关 `strongly_typed: true` 就让所有入口脚本（nsga2 / oos / walkforward）切到 STGP**，旧配置默认 `False` 行为不变。验证脚本 `python -m src.gp.stgp` 做 2000 轮交叉 + 变异压力测试，`非法 0 例`。

## 结果：样本外没改善

500×50 全量 walk-forward，STGP（`exp_20260604_183930`）vs 普通 GP（`exp_20260603_180209`），同配置只差 `strongly_typed`：

| run | 逐折 OOS \|ICIR\| | 均值 | 标准差 | 最差 | 翻转 | 含 rank 占比 | 平均树大小 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 普通 GP | 0.030 / 0.111 / 0.268 | 0.1363 | 0.0985 | 0.0303 | 0/3 | 4.0% | 5.12 |
| STGP | 0.014 / 0.086 / 0.271 | 0.1234 | 0.1081 | 0.0138 | 1/3 | 5.6% | 6.75 |

- **均值 / 最差略低、多一次符号翻转**，但 n=3 折、标准差 ~0.10，均值差 0.013 淹在噪声里——诚实结论是「**没改善**」，不是「STGP 更糟」。两个 run 高度雷同，fold3（2023 regime）几乎一致（0.268 vs 0.271），故事仍被那一折主导。
- **唯一稳的差异：STGP 树更大（6.75 vs 5.12）**，部分是生成偏置（grow-only 初始化 + R 因子须 `rank(内层S)` 天然更大），但它长出更复杂的树却没换来 OOS 收益。
- **含 rank 占比几乎没动（4.0%→5.6%）**——类型系统没把搜索明显往排名因子上引，再次印证这个量价宇宙里 rank 类因子本就不占优。

## 结论

STGP 把搜索空间的垃圾剪干净了（`非法 0 例`），但**样本外一点没动**。这正面证明：**瓶颈不在搜索合法性，而在特征 / 算子贫瘠**——6 个量价终端 + 单一 ICIR 目标，搜索再"干净"，天花板都在那。

STGP 的价值因此是两层：① 概念学习（强类型生成 / 交叉 / 变异的机制）；② **基础设施投资**——等扩了算子（C 节），算子越多、无意义组合越多，STGP 的剪枝价值才真正放大。两者是**叠加**关系。
