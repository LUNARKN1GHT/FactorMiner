# 验证模块 · 样本外验证

## 当前问题

在之前做验证的时候，一直出现 ICIR 高到 4 的问题，实际应用中显然不会出现这样异常的值。其根本原因在选择偏差：GP 搜索了上万个表达式，然后挑出在它见过的这段数据上得分最高的那个。但「得分最高」=既抓住了真信号，又碰巧你和了这段数据里的噪声。

## 处理方法

我们要按时间切分数据集，不能随机打乱数据集。金融本身是时间序列——随机抽测试点会造成「未来信息泄露」。必须**前段训练、后段测试**，时间上完全隔开。

## 完成后的疑问

- 当前分割方式，的确能限制住因子的 ICIR，但因子仍然存在过拟合的问题。在训练数据集上表现好的因子，在后续验证集上的结果会下降最高达到80%。
- 运行分窗口训练时，部分因子还存在负衰减，即在验证集上表现的反而更好了。这一机制原理尚未知。可能是和不同窗口的数据特性有关。

## 滚动窗 walk-forward（2026-06-03 全量）

把单次 holdout 升级成滚动窗：定长 3 年训练段向后滑，各取 1 年测试段，每折在自己的训练段重跑 NSGA-II，再逐个体检 train/test |ICIR|。三个切点 2021/2022/2023，脚本 [`run_gp_walkforward.py`](../scripts/run_gp_walkforward.py)，整条前沿连表达式树落盘 `walkforward.pkl`，后续分析不用重跑 GP。

每折按 train|ICIR| 选出的因子，样本外战绩：

| fold | size | train ICIR | test ICIR | 衰减 |
| ---- | ---- | ---------- | --------- | ---- |
| 1    | 10   | −0.4464    | −0.0303   | 93%  |
| 2    | 10   | −0.4155    | −0.1112   | 73%  |
| 3    | 9    | −0.3885    | −0.2675   | 31%  |

OOS \|ICIR\| 各折 = [0.0303, 0.1112, 0.2675]，均值 0.1363、**标准差 0.0985 ≈ 均值**、最差 0.0303。

读出三点：

1. **没有符号翻转**——train/test 的 ICIR 全是负号（量越大、未来收益越低），方向在样本内外是稳的，不是反指标。
2. **稳定性极差**：标准差几乎等于均值，最差一折（2021）只剩 0.03 ≈ 噪声。均值 0.14 这个数单看会骗人，离散度才是真相。
3. 幸存者清一色量/额（volume/amount）类，价格因子几乎不进前沿——这个 hs300 样本里流动性因子主导。

## 换选择准则的对比（回答「负衰减」之谜）

既然 train-max 可疑，拿 pkl 里整条前沿换几种选法离线重挑，脚本 [`compare_selection.py`](../scripts/compare_selection.py)：

| 选法                  | 均值       | 标准差 | 最差折     |
| --------------------- | ---------- | ------ | ---------- |
| train-max（基线）     | 0.1363     | 0.0985 | 0.0303     |
| min-size（纯简约）    | **0.1706** | 0.1915 | 0.0216     |
| parsimony（简约惩罚） | 0.1289     | 0.0985 | **0.0586** |

- min-size 的高均值是假象：全靠 fold3 的 `amount` 撞上 OOS 0.44 撑起来（这正是之前「负衰减」的来源——简单因子在 2023 这个 regime 反而更强），另外两折是 0.049/0.022 纯噪声，代价是标准差飙到 0.19。
- **真信号穿透所有选法**：不管怎么选，fold1/fold2 的 OOS \|ICIR\| 都 ≤ 0.11，只有 fold3 有真东西。**瓶颈不在「怎么挑」，而在搜出来的本就是一批弱的、靠 regime 的流动性因子。** 在选法上雕花是甲板上摆椅子。
- 「负衰减」之谜由此解开：不是机制问题，是 **n=3 时一折 regime 运气主导了汇总**——2023 恰好奖励流动性因子。

## 显著性校正：重叠 + 选择偏差

均值 0.14 到底显不显著？分两种虚高打。

**虚高① 单因子重叠**（[`significance.py`](../scripts/significance.py)）：5 天前向收益每天滚动重叠 → IC 序列正自相关 → `std(IC)` 低估 → naive `t = ICIR×√N` 虚高。用 Newey-West（Bartlett 核，滞后 horizon−1=4）补回自相关：

| fold | ICIR    | naive_t | NW_t  | p(NW)  | 显著? |
| ---- | ------- | ------- | ----- | ------ | ----- |
| 1    | −0.0303 | −0.47   | −0.25 | 0.80   | ✗     |
| 2    | −0.1112 | −1.73   | −1.04 | 0.30   | ✗     |
| 3    | −0.2675 | −4.16   | −2.32 | 0.0205 | ✓     |

naive→NW 三折一致砍掉约 **1.8×**（理论极限 √5≈2.24），这就是「ICIR 虚高」可量化的实测系数。fold2 的 naive_t=1.73 看着像有东西、NW 一砍剩 1.04，是重叠骗人的典型现场。**三个会被发表的因子里，两个在最宽松的单检验下就和 0 无法区分。**

**虚高② 选择偏差**（[`deflated.py`](../scripts/deflated.py)）：fold3 那 p=0.02 是单次检验值，而它是 GP 从成千上万个表达式里挑的最强者——「挑最强」=「做了 N 次检验取最大」。用 Deflated Sharpe，在 t 空间里 `DSR = Φ(|t| − E[max t])`，把 Part A 的 NW_t 直接继承进来。N 不可精确知，反解 break-even N\*：

| fold | \|NW_t\| | break-even N\* |
| ---- | -------- | -------------- |
| 1    | 0.25     | 2              |
| 2    | 1.04     | 4              |
| 3    | 2.32     | **56**         |

fold3 在不同有效试验数下：N=10 DSR 0.77、N=30 DSR 0.60、**N=100 DSR 0.42（已破 0.5）deflated p=0.87**、N=1000 DSR 0.17。只要 GP 有效试验数 > 56（500 个体×50 代去重去相关后几乎必然），fold3 也判死。

## 结论

**没有任何一个因子经得起「重叠校正 + 选择偏差校正」的双重检验。** 这听着丧，但它恰是样本外流水线最该产出的诚实结论：_别上线_。同时它沉淀了两个可复用的方法学结果——重叠虚高约 1.8× 的实测 haircut，以及 deflated Sharpe 的 break-even N\* 判活法。
