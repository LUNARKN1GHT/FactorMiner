# 因子动物园：生成与筛选解耦

> mentor 给的方向（2026-06-10）：① 筛选用 **IC** 不用 ICIR；② **全批量生成因子存库，再设计独立筛选模块**（在测试集上取 IC 最好的几个）；③ 组合方式点到为止。终点是转 **RL 挖因子**。

## 为什么这么做

之前是「GP 边搜边筛、只吐一条窄 Pareto 前沿」。新架构把**生成**和**筛选**彻底拆开：

```text
generate_factors.py        factor_library.pkl          screen_factors.py
 大批量生成树 → 去重    →   存 (表达式, 树,          →   按 test IC 排序
 → 并行算 train/test IC      train_ic, test_ic, size)     → 取 top-K → 回测
 只生成+存，不筛选           一次生成，反复筛选            筛选逻辑独立可改
```

好处：生成一次、筛选 N 次（改筛选不重跑生成）；因子值不重算；而且这正是 **RL 的底座**（见末尾）。

**指标换成 mean rank IC**（不用 ICIR）：ICIR 的分母 std(IC) 可被近常数因子黑（我们撞过 reward hacking），且 ICIR 高不代表 IC 强（复合因子 ICIR 0.25 但 IC 仅 0.037 不赚钱）。**IC 直连经济幅度**，稳定性维度挪到实际回测里检验——关注点分离。

## 两个脚本怎么用

### 1. 生成因子库 — [`generate_factors.py`](../scripts/generate_factors.py)

```bash
python scripts/generate_factors.py configs/default.yaml \
    --n 5000 --split 2023-01-01 --n-jobs 10
```

- `--n`：目标生成因子数（去重后；冒烟先用 `--n 200`）
- `--split`：train/test 分界日（默认 2023-01-01）
- `--n-jobs`：并行核数（公共服务器占 10）
- 做什么：`ramped_half_and_half` 广撒网生成树 → 按 `str(tree)` 去重 → 退化守卫（每日截面去重中位数 ≥4，挡近常数因子）→ joblib 并行算 train/test **mean rank IC**。
- 落盘到 `results/logs/exp_xxx_factorzoo/`：
  - `factor_library.pkl`：`{config_path, split, factors}`，每个 factor 是 `FactorRecord`（expr / tree / size / train_ic / test_ic / train_icir）
  - `factor_library.csv`：标量表，不开 python 也能 sort 看

### 2. 筛选 + 回测 — [`screen_factors.py`](../scripts/screen_factors.py)

```bash
python scripts/screen_factors.py \
    results/logs/exp_xxx_factorzoo/factor_library.pkl --topk 20 --bt 5
```

- `--topk`：按 `|test IC|` 排序取前几名打印（IC 可正可负，绝对值=预测强度）
- `--bt`：对前几名做**测试段** long-only T+1 回测（负 IC 自动翻转买底分位）
- 输出：top-K 的 train_ic / test_ic / size / expr 表，加前 `--bt` 名的多头 T+1 sharpe / 年化

## 关键纪律一：按 train 选、test 只验

第一版按 **test IC** 选 top 直接翻车——top 因子 train_ic≈0.01 / test_ic≈0.07，差 7–12 倍，是「在测试集上挑最走运的」= 选择偏差。正确口径：**按 train_ic 选（selection），test_ic 只作 OOS 验证、绝不参与选**。`screen_factors.py` 已改成按 `abs(train_ic)` 排序。报 winner 仍把它喂 [`deflated.py`](../scripts/deflated.py) 盖章（见 [验证模块](./验证模块.md)）。

## 关键纪律二：训练段必须在同一 regime 内（最重要）

A 股纯量价因子效力在 **2020→2021 有 regime 断点**，跨断点选会被反相关坑死（全库 rho 从同 regime 的 **+0.80** 掉到跨断点的 **−0.30**）。生成时务必用 `--train-start 2021-01-01` 把训练段限在当前 regime，否则 train 选 test 验全失效。完整机制见 [regime断点.md](./regime断点.md)——这是本架构跑出的最硬结论。

```bash
# 正确：训练段限在 2021 起，避开 2020 断点
python scripts/generate_factors.py configs/default.yaml \
    --n 5000 --split 2023-01-01 --train-start 2021-01-01 --n-jobs 10
```

## 通往 RL 的桥

这套架构是 RL 挖因子（AlphaGen 范式）的底座，到时**换生成器、不推倒重来**：

- 「生成器 ↔ 筛选模块」解耦后，RL 就是把生成器从 GP 换成 PPO（策略网络逐 token 生成表达式）；
- 「用 IC 筛选/回测」直接变成 RL 的 **reward**；
- `factor_library.pkl` 里的 `(表达式, test_ic)` 是设计奖励、做对照的现成数据。
