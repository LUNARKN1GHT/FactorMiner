# 适应度函数纵深（B+ 节）

## 动机

A–D 一路实验的最大教训：**杀死每个因子的头号元凶是过拟合 / regime 依赖**。而现有适应度奖励的恰是「样本内峰值 |ICIR|」——正是过拟合的东西。把"验证阶段才发现的稳定性"前置进搜索目标，是最对症的改进方向。

## ① 时序稳定性适应度

### 设计

把训练段切成 K=3 个子区间，各自算带符号 ICIR，适应度取稳健聚合：

```
score = |mean(ICIR_k)| − λ·std(ICIR_k)
```

- `|mean|`：奖励跨期方向一致、量级稳定的因子
- `−λ·std`：惩罚某段特别强、某段特别弱的"一折运气"因子
- `abs`：方向不限，正负方向一致的因子都能得分（见下方「方向盲区」）
- 只改 `make_objective` 一处，NSGA-II / 选择 / 评估零改动

### 结果

walk-forward 500×50，与上轮扩算子对比：

| run | OOS 均值 | 标准差 | 最差折 |
|---|---|---|---|
| 扩算子 | 0.1593 | 0.0663 | 0.0868 |
| ① 时序稳定性 | 0.2059 | 0.1210 | 0.0348 |

显著性变化：

| fold | 上轮 NW_t | 本轮 NW_t | p(NW) | 显著? |
|---|---|---|---|---|
| 1 | 0.74 | 0.29 | 0.77 | ✗ |
| 2 | 1.29 | **2.84** | **0.0045** | ✓ |
| 3 | 2.23 | **2.59** | **0.0097** | ✓ |

fold2 是**整个项目里统计质量最高的因子**：NW_t=2.84，break-even N*=255，在合理的有效试验估计（N≈10–30）下首次通过 deflated Sharpe。

### 发现：方向盲区

稳定性适应度的 `abs(arr.mean())` 对正负 ICIR 一视同仁——它选出的是「跨期一致」的因子，但一致负方向和一致正方向都能得高分。本轮 fold2/fold3 的测试 ICIR 均为 **-0.29**（统计显著的负方向信号），直接喂给多头回测，三折全部负 sharpe。

这不是适应度设计的错——**负 ICIR 因子本身是有效反转信号**，A 股多头策略只需翻转因子方向（买底分位）即可利用。问题在于回测方向未处理。

**修法**：`run_backtest.py` 喂入回测前加一行：

```python
if pick["train_icir"] < 0:
    fac = -fac
```

这行代码让「低因子值」成为「高预测」，多头买顶分位才正确。修复后 fold2 的实盘表现待重跑验证。

### fold1 崩塌的原因

fold1 OOS |ICIR| 从 0.087 退化到 0.035。稳定性适应度选到了训练期三段全负方向（均值 ≈ -0.45）的 volume 嵌套因子，稳定性分数很高，但 OOS regime 切换后方向翻正——这是稳定性适应度**无法防护的样本外 regime 切换**，不是设计缺陷，是因子挖掘的内在上限。

## ② 正交性压力（跑中）

在 ① 基础上叠加正交性惩罚：

```
score = |mean(ICIR_k)| − STAB_LAMBDA·std(ICIR_k) − ORTH_LAMBDA·|corr(factor, amount)|
```

动机：几轮实验的幸存因子清一色是量/额类（`volume`/`amount`/`ts_corr(amount,...)`）——搜索陷入「流动性吸引盆」。正交性压力逼搜索逃离这个吸引盆，去找与 amount 不相关的信号。

`a_rank`（amount 的截面排名）在闭包里预计算，只用训练段数据，无测试集泄露。

## ③ hoist/shrink 变异（待实现）

直接砍 bloat：`ts_std(ts_std(ts_std(...)))` 这类纯平滑堆叠在前沿里反复出现，增加树大小但不增加信息。

- **hoist**：用子树替换掉其父节点（把孙子提升到儿子位置），剪掉无用的中间层
- **shrink**：把一个内部节点替换成它的某个叶子终端，直接缩树
