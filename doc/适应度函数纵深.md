# 适应度函数纵深（B+ 节）

## 动机

A–D 一路实验的最大教训：**杀死每个因子的头号元凶是过拟合 / regime 依赖**。而现有适应度奖励的恰是「样本内峰值 |ICIR|」——正是过拟合的东西。把"验证阶段才发现的稳定性"前置进搜索目标，是最对症的改进方向。

## ① 时序稳定性适应度

### 设计

把训练段切成 K=3 个子区间，各自算带符号 ICIR，适应度取稳健聚合：

```txt
score = |mean(ICIR_k)| − λ·std(ICIR_k)
```

- `|mean|`：奖励跨期方向一致、量级稳定的因子
- `−λ·std`：惩罚某段特别强、某段特别弱的"一折运气"因子
- `abs`：方向不限，正负方向一致的因子都能得分（见下方「方向盲区」）
- 只改 `make_objective` 一处，NSGA-II / 选择 / 评估零改动

### 结果

walk-forward 500×50，与上轮扩算子对比：

| run          | OOS 均值 | 标准差 | 最差折 |
| ------------ | -------- | ------ | ------ |
| 扩算子       | 0.1593   | 0.0663 | 0.0868 |
| ① 时序稳定性 | 0.2059   | 0.1210 | 0.0348 |

显著性变化：

| fold | 上轮 NW_t | 本轮 NW_t | p(NW)      | 显著? |
| ---- | --------- | --------- | ---------- | ----- |
| 1    | 0.74      | 0.29      | 0.77       | ✗     |
| 2    | 1.29      | **2.84**  | **0.0045** | ✓     |
| 3    | 2.23      | **2.59**  | **0.0097** | ✓     |

fold2 是**整个项目里统计质量最高的因子**：NW_t=2.84，break-even N\*=255，在合理的有效试验估计（N≈10–30）下首次通过 deflated Sharpe。

### 发现：方向盲区

稳定性适应度的 `abs(arr.mean())` 对正负 ICIR 一视同仁——它选出的是「跨期一致」的因子，但一致负方向和一致正方向都能得高分。本轮 fold2/fold3 的测试 ICIR 均为 **-0.29**（统计显著的负方向信号），直接喂给多头回测，三折全部负 sharpe。

这不是适应度设计的错——**负 ICIR 因子本身是有效反转信号**，A 股多头策略只需翻转因子方向（买底分位）即可利用。问题在于回测方向未处理。

**修法**：`run_backtest.py` 喂入回测前加一行：

```python
if pick["train_icir"] < 0:
    fac = -fac
```

这行代码让「低因子值」成为「高预测」，多头买顶分位才正确。修复后 fold2 的实盘表现待重跑验证。

### fold1 崩塌的原因

fold1 OOS |ICIR| 从 0.087 退化到 0.035。稳定性适应度选到了训练期三段全负方向（均值 ≈ -0.45）的 volume 嵌套因子，稳定性分数很高，但 OOS regime 切换后方向翻正——这是稳定性适应度**无法防护的样本外 regime 切换**，不是设计缺陷，是因子挖掘的内在上限。

## ② 正交性压力（跑中）

在 ① 基础上叠加正交性惩罚：

```txt
score = |mean(ICIR_k)| − STAB_LAMBDA·std(ICIR_k) − ORTH_LAMBDA·|corr(factor, amount)|
```

动机：几轮实验的幸存因子清一色是量/额类（`volume`/`amount`/`ts_corr(amount,...)`）——搜索陷入「流动性吸引盆」。正交性压力逼搜索逃离这个吸引盆，去找与 amount 不相关的信号。

`a_rank`（amount 的截面排名）在闭包里预计算，只用训练段数据，无测试集泄露。

### 结果：惩罚失效——「关系类」amount 用法从缝里钻出来

fold2 选出的最强因子是 `ts_corr(scale(amount), scale(high))`——**仍然以 amount 为输入**，正交惩罚没拦住。原因诊断清楚：

- 惩罚测的是「因子值 vs amount **水平**的截面相关」；
- 但 `ts_corr(amount, high)` 是 amount 与 high 的**滚动相关系数**，取值 ∈[-1,1]，**与 amount 绝对水平不单调**；
- 故它与 amount 水平相关极低 → 惩罚 ≈ 0 → 穿过守卫。

惩罚只挡得住「amount 的单调变换」（`volume`/`amount`/`ts_std(amount)`），挡不住「**以 amount 为输入的关系类因子**」。fold1/fold3 确实被推成 rank/ts_corr 组合（不再是裸 volume），说明 ② 对**水平类**流动性因子有效；但价量**关系**因子从缝里钻出来。

**真发现**：在这个量价宇宙里，amount 不只以"水平"出现，还以"关系"出现。想真正正交得换惩罚口径（如惩罚「与 amount 因子本身的 rank 相关」而非「与 amount 水平」），或承认 amount 衍生信号就是这宇宙里最强的。正交化比想象的难，惩罚项的"量纲"必须对准你想剥离的东西。

### 副产物：② 反而选出统计质量最高的因子

|                 | ① 稳定性 | ② 正交                                            |
| --------------- | -------- | ------------------------------------------------- |
| fold2 NW_t      | 2.84     | **3.40**                                          |
| p(NW)           | 0.0045   | **0.0007**                                        |
| break-even N\*  | 255      | **1690**                                          |
| deflated 通过到 | N≈30     | N=10/30 过（p=0.0067/0.0199），N=100 挂（0.0649） |

② 选出一个更干净的价量关系因子（`ts_corr(amount, high)` 家族），是整个项目统计质量最高、**首次稳过小 N deflated** 的因子。

### 但实盘多头仍亏：截面排序 ≠ 多头绝对 PnL（D 节结论复现）

方向修正（负 ICIR 因子翻转买底分位）后，fold1 转正、fold2 亏损收窄，但 fold2/fold3 测试段（2022 熊市）多头绝对回测仍负——**截面排序对，但熊市里"相对最强"的票也跌**。这正是 [回测现实性](./回测现实性.md) 的核心结论：ICIR 衡量截面预测力，实盘多头 PnL 取决于篮子绝对涨跌，两者不是一回事。

## ③ hoist/shrink 变异（待实现）

直接砍 bloat：`ts_std(ts_std(ts_std(...)))` 这类纯平滑堆叠在前沿里反复出现，增加树大小但不增加信息。

- **hoist**：用子树替换掉其父节点（把孙子提升到儿子位置），剪掉无用的中间层
- **shrink**：把一个内部节点替换成它的某个叶子终端，直接缩树

## 综合结论（持续更新）

| 改进            | 机制               | 效果                                                                                                       |
| --------------- | ------------------ | ---------------------------------------------------------------------------------------------------------- |
| 扩算子（C1+C2） | 特征更丰富         | OOS 均值 0.14→0.16，地板抬高，方差降低                                                                     |
| ① 时序稳定性    | 目标函数前置稳定性 | fold2 NW_t 1.3→2.8，首次通过显著性；暴露方向 bug                                                           |
| ② 正交性压力    | 惩罚与 amount 同质 | 惩罚口径打偏（只挡水平、不挡关系），但副产物是统计质量最高的因子（fold2 NW_t 3.40，首次稳过小 N deflated） |

核心教训：**搜索目标才是瓶颈**，不是搜索算法（STGP 证明）、不是算子（扩算子只抬地板），而是「奖励什么」决定了能挖到什么。

## 收口结论

适应度纵深三步走到 ②，得到整个项目最完整的一条故事线：

1. **能找到统计上真实显著的信号**：① 把"跨期稳定"前置进搜索目标，fold2 NW_t 从 1.3 抬到 2.8；② 进一步选出 `ts_corr(amount, high)` 家族，NW_t 3.40、小 N 下首次稳过 deflated Sharpe。**这是项目里第一次出现经得起重叠 + 选择偏差双重校正的因子**。
2. **但落不了地**：方向修正后实盘多头在 2022 熊市仍亏——截面排序预测力 ≠ 多头绝对 PnL（D 节结论复现）。
3. **正交化是门没做完的功课**：想剥离的东西（amount）以"水平 + 关系"两种形态存在，惩罚项的量纲必须对准目标，否则关系类用法从缝里钻出。这是留给后续的明确方向。

**最终判决**：A 股高效市场 + 多头约束下，纯量价 GP 能挖到统计显著的真信号，但难以转化为可落地的多头超额。这不是流水线的失败，而是诚实流水线在高效市场该有的结论。

工程上沉淀出统一评估入口 [`evaluate_run.py`](../scripts/evaluate_run.py)：一个 pkl 进、数据只读一次、每折树只求值一次，一次跑完「方向修正 → 测试段回测三层 → NW 显著性 → deflated 存活线」。

③ hoist/shrink 变异属 bloat 治理，与"能否挖到真信号"的主线无关，留作后续工程优化。
