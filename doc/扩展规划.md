# 扩展方向规划

> **定位**：mentor 以学习为主、不赶成果。所以下面的优先级按**概念学习价值**排，
> 而不是按"最快出结果"或"做新成果"排。6/10 是学习节点，不是硬产出压力。

## 当前进度：已完成的闭环

一条完整的"挖 → 评 → 测"链路 + 一批 GP 进阶模块：

- **挖**：GP 引擎（表达式树 / 三类算子 / 锦标赛选择 / 子树交叉变异）
- **评**：IC / ICIR（Rank IC，截面预测力）
- **测**：成本回测（不重叠调仓 + 换手手续费 + 夏普 / 最大回撤 / 年化）
- **进阶模块**：ramped half-and-half 初始化、深度门禁、parsimony 简约压力、
  NSGA-II 多目标（含基因型去重保多样性）

**已知但暂未处理**：结果均为样本内，高复杂度因子 ICIR 虚高（过拟合）。

## 待扩展方向（按学习价值分组）

### A. 因子质量与验证 ← 下一站

- **样本外验证 / walk-forward**（首选）：切训练-测试 / 滚动窗口，证明因子非过拟合。
- 因子去冗余 / 正交化：与已有因子库正交，只留增量信息。
- 多重检验校正（deflated Sharpe）：校正"搜上万个挑最好"的乐观偏差。
- 稳健性测试：换股票池 / 时段 / 参数看稳定性。

### B. GP 算法纵深

- **强类型 GP（STGP）**：给算子标类型（截面维 / 时序维 / 标量），只生成合法因子，
  禁止 `rank(rank(x))`、`ts_mean(x, close)` 这类无意义组合。
- 变异算子家族：point / hoist / shrink mutation，不同探索粒度。
- lexicase 选择 / 岛模型：更强的多样性保持，缓解早熟。
- 热启动：用已知 alpha（Alpha101 等）做初始种群。

### C. 算子集与数据

- 扩充算子：`ts_corr / ts_max / ts_argmax / scale / decay_linear / sign / power` …
- 中性化算子：行业 / 市值中性，剥离风格暴露。
- 引入新数据：基本面、资金流、另类数据。

### D. 回测与组合现实性

- 更真实的回测：涨跌停、停牌、T+1、冲击成本 / 滑点。
- 组合构建：从单因子打分升级到带风险模型 / 约束的组合优化。
- 多因子合成：把 GP 挖的多个因子合成复合因子。

### E. 工程与规模

- 并行评估：适应度评估天然可并行（multiprocessing / joblib），提速数倍。
- 真正用上 H100：因子求值搬 GPU（cupy / cudf），或走下面的 RL 方向。
- 子树求值缓存：相同子树不重复算。
- 实验追踪：配置版本化、随机种子、结果可复现。

### F. 研究前沿（想"超越复现"再看）

- AlphaGen 类（RL 搜 alpha）：用 PPO 代替 GP 搜表达式，吃满 GPU。
- 多目标深化：IC + 换手 + 容量 + 相关性 多目标（已有 NSGA-II 底子）。
- 神经符号 / LLM 辅助因子生成：最前沿、风险高。

## 下一步：样本外验证（A）

**为什么先做它**：能当场解开我们一路撞见的所有谜题——为什么 ICIR 会虚高到 4、
为什么"在出题的卷子上考满分"不算数。学完，认知闭环从"挖→评→测"补全为
"挖→评→**验**→测"，是整条因子挖掘理解的分水岭。

**计划**：

1. 按日期切训练段 / 测试段，只在训练段进化；
2. 在没碰过的测试段重算 IC / ICIR，对比同一因子"样本内 vs 样本外"；
3. 进一步：walk-forward（滚动训练-测试），看因子随时间的稳定性。
