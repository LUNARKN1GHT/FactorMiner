# 遗传规划（GP）挖掘因子 · 学习笔记

> 本笔记对照本项目骨架代码（`src/gp/`、`src/evaluation/`）整理，便于把理论和实现一一对应。

## 1. 核心思想

把"找公式"建模成"模拟进化"：一个因子表达式 = 一个个体，一群表达式 = 种群。
适应度高（预测力强）的个体更容易留下后代，逐代逼近好因子。

五步主循环（对应 `engine.py:run_gp`）：

```text
1. 初始化种群   ── random_tree 随机生成表达式
2. 评估适应度   ── fitness_fn(个体)   ← 待实现，项目下一步
3. 选择         ── tournament_select 锦标赛选优
4. 交叉 + 变异  ── crossover / mutate 产生下一代
5. 回到第 2 步，循环 generations 代
```

## 2. 表示：表达式树（`tree.py`）

公式天然是一棵树，例 `div(close, ts_mean(volume, 20))`：

```text
        div
       /    \
    close   ts_mean
            /     \
        volume     20
```

- 内部节点 = **算子**（function）：来自 `operators.py`
- 叶节点 = **终端**（terminal）：行情字段或常量

`Node` 字段：`name`(算子名) / `arity`(参数数) / `children`(子树) / `value`(叶节点字段或常量)。
关键方法：`depth()` 控制复杂度，`size()` 用于防膨胀。

**GP 两大基本配置：**

- 算子集 Function Set = `BINARY_OPS + UNARY_OPS + TS_OPS`
- 终端集 Terminal Set = `TERMINALS = [open, high, low, close, volume, amount]`

## 3. 算子集：为什么分三类（`operators.py`）

金融数据是 **(时间 × 股票)** 面板，算子按维度分三种：

1. **逐元素算子** `add/sub/mul/div/neg/abs/log`：对每个 (日期,股票) 单独算。
   - `protected_div` 除零返回 0、`log_op` 对非正数返回 0 —— **保护性算子**是 GP 必备，
     随机公式必须对任意输入都不崩溃。
2. **截面算子** `rank`：同一天、所有股票之间横向比较，归一到 [0,1]。
   选股本质是横截面比较，故极重要。
3. **时序算子** `ts_mean/ts_std/ts_rank/delay/delta`：单只股票、时间窗口内纵向计算，
   多一个 window 参数，取值来自 `TS_WINDOWS = [5,10,20]`。

> ⚠️ **待修的坑**：`random_tree` 把时序算子当普通 arity=2 算子，第二参数会被填成子树/字段
> （如 `ts_mean(close, volume)`），而非窗口整数。写求值器时需约束：时序算子第二参数
> 必须是 `TS_WINDOWS` 里的常数。

## 4. 适应度：怎么判断因子好坏（`metrics.py`）—— 项目灵魂

因子好 = 今天的因子值能预测股票未来收益。

- **IC（信息系数）** `calc_ic`：每天，全部股票的"因子值"与"未来 N 日收益"的相关系数。
  默认 **Rank IC (Spearman)**，只看排序、对异常值稳健，业界默认。
  直觉：IC≈0.05 不错，0.1 已很强，不要期待 0.5。
- **ICIR = mean(IC)/std(IC)** `calc_icir`：IC 的信噪比，同时奖励"高"和"稳"，
  是更好的适应度目标。
- **分组收益** `group_returns`：按因子值分 5 组，看 G1→G5 收益是否单调，回测用。

评估数据流：

```text
表达式树 ──求值──► 因子矩阵 (date×code)
                      │ 与 未来收益矩阵对齐
              calc_ic_series ──► 每日 IC 序列
                      │
               calc_icir ──► 标量 = 适应度
```

`fitness_fn(node)` 内部三步：① 把树求值成因子矩阵 ② 算 IC 序列 ③ 返回 ICIR。
**最大缺口 = 求值器（evaluator）**：把 `Node` 树翻译成对真实数据的 numpy/pandas 运算。

## 5. 选择：适者生存（`tournament_select`）

- **锦标赛选择**：随机抽 `tournament_size=5` 个，取适应度最高者当父代。
  高适应度更易被选，低的也有机会 → 保持多样性，比"只选最好"更不易早熟。
- **精英保留**（`engine.py`）：每代把当前最优个体原样复制进下一代，最好解永不丢失。

## 6. 交叉与变异：制造新公式

- **子树交叉 crossover**（prob=0.7，探索主力）：两父代各随机选一节点，交换其整棵子树。
- **子树变异 mutate**（prob=0.2）：随机选一节点，子树替换成全新随机树，引入新基因防同质化。

> 💡 **bloat（膨胀）**：进化中树会无意义增大（耗内存、过拟合、难读）。
> 对策：适应度加长度惩罚 `fitness - λ·size`，或限制 `max_depth`（config 已有 =6，惩罚未加）。

## 7. 主循环全景（`run_gp`）

```python
population = [random_tree(...) for _ in range(500)]      # 初始化
for gen in range(50):
    fitnesses = [fitness_fn(ind) for ind in population]  # 评估 ← 待实现
    best = argmax(fitnesses); 记录 best_history          # 监控
    next_pop = [best]                                    # 精英保留
    while 未填满:
        if rand < 0.7:  交叉两个锦标赛父代
        else:           选一个，0.2 概率变异
    population = next_pop                                 # 换代
```

唯一缺口就是 `fitness_fn`，故路线图为：对接数据源 → 实现求值器+适应度 → 首次进化。

## 8. 推荐资源（按性价比）

1. **Koza《Genetic Programming》(1992)** —— GP 开山之作，读前 4 章即可。
2. **《A Field Guide to Genetic Programming》** —— 免费 PDF（gp-field-guide.org.uk），
   最适合入门，full/grow/ramped 初始化、bloat 讲得全。
3. **WorldQuant《101 Formulaic Alphas》** —— 看真实因子长相，启发算子设计。强烈推荐。
4. **DEAP 文档 Symbolic Regression 教程** —— 用 DEAP 做 GP 的标准范例，对照手写实现。
5. **gplearn 源码** —— Python 符号回归库，实现干净可借鉴。
